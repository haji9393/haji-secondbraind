# Sự nghiệp của Haji (tìm việc và CV)

Skill gộp 3 skill cũ. Mở đúng file trong `references/` theo việc cần làm, không đọc hết một lúc.

## Khi nào dùng
| Việc | Mở file |
|---|---|
| Xem JD có hợp không, chọn kênh nộp, lịch sử nộp, knockout answers, message recruiter, trả lời câu hỏi khoảng trống | `references/haji-job-targeting.md` |
| Viết hoặc chỉnh CV theo một JD cụ thể, xuất bản 2 cột | `references/haji-cv-builder.md` (luôn kèm file kho dữ kiện bên dưới) |
| Tra số liệu, timeline, framing bắt buộc, Red List | `references/haji-cv-evidence-bank.md` |

## Thứ tự chuẩn khi có JD mới
1. `haji-job-targeting.md`: chấm độ phù hợp và chọn kênh. Không hợp thì dừng, báo lý do.
2. `haji-cv-evidence-bank.md`: lấy dữ kiện, chỉ dùng số đã khoá.
3. `haji-cv-builder.md`: ráp CV, chạy checklist, xuất file.

Viết message hay post LinkedIn theo giọng Haji thì kết hợp skill `haji-writing`.
